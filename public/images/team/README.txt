NSM Limited - Team Member Images Folder
=========================================

Place team member images here. Example filenames:
- kawsar-hossain.png (or .jpg)
- mahbubur-rahman.jpg
- amit-sen.jpg
- afroza-sultana.jpg

Supported formats: PNG, JPG, JPEG, WEBP, SVG
Recommended aspect ratio: 1:1 square (e.g. 600x600 px or 800x800 px) with centered face portrait.

In src/views/TeamView.vue, specify the image path like:
image: '/images/team/kawsar-hossain.png'

Note: If an image is not added or fails to load, the website will automatically display a cyber-styled initials avatar badge so it never looks broken!
